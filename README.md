# 📘 ADS Estudos

Repositório com meus estudos do curso de Análise e Desenvolvimento de Sistemas.

## 🎯 Objetivo

Organizar conteúdos, exercícios e projetos de cada disciplina ao longo do curso.

## 🗂️ Estrutura

- 01 - Lógica de Programação
- 02 - Algoritmos e Estruturas de Dados
- 03 - Engenharia de Software
- 04 - Banco de Dados
- 05 - Redes de Computadores

Cada pasta contém:

- Aulas (resumos)
- Exercícios
- Projetos

## 🚀 Como usar

Navegue pelas pastas por disciplina e acesse:

- `aulas/` → resumos
- `exercicios/` → prática
- `projetos/` → aplicações reais
